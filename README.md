# Blinkit Sales Dashboard using Power BI

## 📊 Project Overview

The **Blinkit Sales Dashboard** is a business intelligence and data visualization project developed using Microsoft Power BI. It transforms retail sales data into interactive visualizations to help users explore sales performance, product categories, outlet characteristics, and key performance indicators (KPIs).

The project demonstrates the practical use of data cleaning, data transformation, DAX measures, and interactive dashboard design.

## 🎯 Objectives

- Analyze retail sales data using Power BI.
- Present key performance indicators through interactive visualizations.
- Compare sales across product categories and outlet types.
- Use filters and slicers to explore different segments of the dataset.
- Develop practical skills in data analysis and business intelligence.

## 🛠️ Technologies Used

- **Microsoft Power BI Desktop** — Dashboard development and data visualization.
- **Power Query** — Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** — KPI calculations and analytical measures.
- **CSV / Excel** — Source data format, depending on the dataset.

## 📈 Dashboard Features

The dashboard may include the following features, depending on the final implementation:

- Total Sales KPI
- Average Sales KPI
- Total Item or Record Count
- Average Rating
- Sales by Item Type
- Sales by Outlet Type
- Outlet Size and Location Analysis
- Interactive slicers and filters

## 🚀 How to Run the Project

1. Install Microsoft Power BI Desktop.
2. Clone or download this GitHub repository.
3. Open `Blinkit_Sales_Dashboard.pbix` in Power BI Desktop.
4. If prompted, configure the data source using the correct dataset location.
5. Refresh the data if required and permitted.
6. Explore the dashboard using the available charts, slicers, and filters.

## 🧹 Data Preparation

Power Query can be used to inspect and clean the dataset, correct data types, handle missing values, and prepare the data for analysis.

DAX measures are used to calculate the KPIs displayed in the report. The exact transformations and calculations depend on the source dataset and final dashboard implementation.
